# 2. 项目食用指南
首先，请确保您的开发环境已安装 **Python 3.10.19。**  
本项目的核心亮点在于集成了 AI 能力，因此您需要**先在本地搭建 Ollama 服务**，这是实现智能交互的关键基石。  
在启动项目前，**请重点关注 config.py 文件**。这里不仅是**数据库连接的配置中心**，也是用户注册功能的“总控台”——我们需要您在此处填入**正确的邮箱服务参数**，以便系统能够发送验证码，保障账户安全。
